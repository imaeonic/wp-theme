# Rismor WordPress Theme

A bespoke, premium, fully customisable WordPress block theme for Rismor Technologies Ltd.

This repository targets modern WordPress Site Editing rather than a page-builder dependency. The goal is to ship an opinionated, high-end default design while keeping layouts, typography, colour, spacing, templates, template parts and reusable sections editable from WordPress.

## Principles

- Native WordPress block theme and Full Site Editing.
- No Elementor, Divi, Bootstrap or proprietary builder lock-in.
- `theme.json` is the design-system source of truth.
- Core blocks first; custom blocks only where core cannot provide the required experience.
- Reusable editable patterns for polished page sections.
- Multiple global style variations.
- Responsive, accessible and performance-first.
- Presentation belongs in the theme; business functionality belongs in plugins.
- No hard-coded customer content required for the theme to function.

## Target

- WordPress 7.1+
- PHP 8.1+
- Modern evergreen browsers

The full architecture and implementation notes are being added with the initial theme scaffold.
