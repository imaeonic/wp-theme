A premium, fully customisable WordPress block theme built for Rismor Technologies.

== Description ==

Rismor is a native WordPress block theme designed around Full Site Editing and Global Styles. It ships with a premium default visual system while preserving native editor control over templates, template parts, typography, colour, spacing, borders, shadows and reusable page sections.

The theme does not require Elementor, Divi, Bootstrap or a proprietary page builder.

== Features ==

* Native WordPress 7.1 block theme.
* Full Site Editing support.
* theme.json design system.
* Fluid typography and responsive editor controls.
* Editable header and footer template parts.
* Standard page, post, search and 404 templates.
* Landing, blank-canvas and sidebar page templates.
* Reusable editorial block patterns.
* Multiple global style variations.
* Custom block style choices.
* Reduced-motion-aware progressive animation.
* Accessibility-conscious focus states and semantics.
* WooCommerce-friendly architecture with no template lock-in.
* No tracking, analytics or external requests added by the theme.

== Privacy ==

The Rismor theme does not collect, transmit or store visitor data and does not add analytics or tracking. Site owners may add plugins or third-party services that have their own privacy implications.

== Installation ==

1. Copy the theme folder to wp-content/themes/rismor or upload a release ZIP in Appearance > Themes.
2. Activate Rismor.
3. Open Appearance > Editor to customise Styles, templates and template parts.
4. Replace starter pattern content with production content and media.
